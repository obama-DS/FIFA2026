================================================================================
MATCH PROBABILITY ENGINE - PHASE 18
================================================================================

PURPOSE
-------
Calculates match outcome probabilities using Poisson distribution based on
expected goals from ML models. Reusable by Season Oracle and Beat the AI API.

LOCATION
--------
src/predictions/match_probabilities.py

KEY COMPONENTS
--------------

1. MatchProbabilityEngine Class
   - Main probability calculation engine
   - Uses scipy.stats.poisson for scoreline distributions
   - Configurable max_goals parameter (default: 10)

2. calculate_match_probability() Function
   - Convenience function for single calculations
   - Wraps MatchProbabilityEngine

CALCULATIONS
------------

Input:
- expected_home_goals: float (from ML model)
- expected_away_goals: float (from ML model)

Output Dictionary:
- expected_home_goals: Input value (rounded to 3 decimals)
- expected_away_goals: Input value (rounded to 3 decimals)
- home_win_prob: Probability of home win (0-1, rounded to 4 decimals)
- draw_prob: Probability of draw (0-1, rounded to 4 decimals)
- away_win_prob: Probability of away win (0-1, rounded to 4 decimals)
- most_likely_result: 'H', 'D', or 'A'
- scoreline_distribution: 2D numpy array of all scoreline probabilities
- most_likely_scorelines: Top 10 scorelines with probabilities

PROBABILITY CALCULATION METHOD
------------------------------

1. Poisson Distribution:
   - P(home scores i) = poisson.pmf(i, lambda=expected_home_goals)
   - P(away scores j) = poisson.pmf(j, lambda=expected_away_goals)

2. Joint Probability (assumes independence):
   - P(scoreline i-j) = P(home scores i) × P(away scores j)

3. Outcome Probabilities:
   - P(home win) = sum of P(i-j) where i > j
   - P(draw) = sum of P(i-j) where i == j
   - P(away win) = sum of P(i-j) where i < j

VALIDATION
----------

The engine validates:
1. All probabilities are between 0 and 1
2. Home/Draw/Away probabilities sum to 1.0 (±0.01 tolerance)
3. All scoreline probabilities sum to 1.0 (±0.01 tolerance)
4. Most likely scorelines are sorted by probability
5. Expected goals are non-negative

Input Validation:
- Rejects None, NaN, Inf values
- Rejects negative expected goals
- Rejects unreasonably high values (>20 goals)

USAGE EXAMPLES
--------------

Example 1: Basic calculation
```python
from src.predictions.match_probabilities import calculate_match_probability

result = calculate_match_probability(
    expected_home_goals=1.8,
    expected_away_goals=1.3
)

print(f"Home win: {result['home_win_prob']:.1%}")
print(f"Draw: {result['draw_prob']:.1%}")
print(f"Away win: {result['away_win_prob']:.1%}")
print(f"Most likely: {result['most_likely_result']}")
```

Example 2: With engine object
```python
from src.predictions.match_probabilities import MatchProbabilityEngine

engine = MatchProbabilityEngine(max_goals=10)

result = engine.calculate_match_probabilities(2.3, 1.1)

# Get top 3 scorelines
for scoreline in result['most_likely_scorelines'][:3]:
    print(f"{scoreline['scoreline']}: {scoreline['probability']:.1%}")

# Validate result
validations = engine.validate_probabilities(result)
if all(validations.values()):
    print("Valid probabilities")
```

MATHEMATICAL PROPERTIES
-----------------------

Independence Assumption:
- Assumes home and away goals are independent events
- Reasonable for goal-scoring in football
- Slight correlation exists in reality (defensive/attacking balance)

Poisson Appropriateness:
- Suitable for rare events (goals)
- Captures randomness in low-scoring games
- Standard approach in football statistics

Limitations:
- Does not account for:
  * Tactical changes during match
  * Momentum shifts
  * Red cards or injuries
  * Weather conditions
  * Home advantage beyond goal expectation

PERFORMANCE
-----------

Typical execution time:
- Single calculation: <1ms
- Batch of 380 fixtures: ~100ms
- 10,000 season simulations: ~2-3 minutes (with sampling)

Memory usage:
- Scoreline distribution: (max_goals+1)² × 8 bytes
- Default (max_goals=10): 121 floats = ~1KB per fixture

ERROR HANDLING
--------------

ValueError raised for:
- None or NaN values
- Negative expected goals

All errors include descriptive messages.
